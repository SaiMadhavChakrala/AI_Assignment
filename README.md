## 📦 Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/SaiMadhavChakrala/AI_Assignment.git
cd AI_Assignment
```

### 2. Create a Virtual Environment
Python 3.8 or higher is recommended.

```bash
python3 -m venv venv
```

### 3. Activate the Environment

- On **Linux/macOS**:
  ```bash
  source venv/bin/activate
  ```

- On **Windows**:
  ```bash
  venv\Scripts\activate
  ```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Code

Run the appropriate script for each experiment:

```bash
python3 Q1/Q1.py          # Runs DFBnB on FrozenLake
python3 Q2/Q2_correct.py  # Runs IDA* on FrozenLake
python3 Q3/q3_start.py        # Runs Hill Climbing with 2-opt on TSP
python3 Q4/q4_cor.py        # Runs Simulated Annealing on TSP
```
The gifs and graphs are saved in the respective folders
